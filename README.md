Unofficial visual guide to the NetNewsWire codebase — a capability map plus source-cited flow diagrams showing how its features are built and how data moves through them.

## What is this

This is a source-code walkthrough of a NetNewsWire fork (`https://github.com/elonwoo/NetNewsWire`), based on commit `512e461782a2d283d71a07f08e38201bf38da310`.

The guide contains one capability map, one domain architecture map, and six workflows. Every node in every diagram is annotated with its source file and line number, and the diagram UI links straight back to the original location on GitHub. All diagrams are generated from the JSON IR under `ir/` and pass structural validation.

The site is purely static: just open `index.html`, or deploy it to Cloudflare Pages as-is — no build step required.

## Layout

| Path | Description |

## How the diagrams are generated

Each diagram is generated by archify from `ir/*.json` and passes four gates in order:

1. `validate` — IR structural validation
2. `deliver` — artifact output and self-containment check
3. `check` — diagram structure and edge rules check
4. `browser-check` — in-browser rendering and interaction test

All eight diagrams pass all four gates (8 × 4 = 32 checks).
